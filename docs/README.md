# Interview Practice Platform — Project Documentation

This folder contains the documentation set for **Interview Practice Platform**, a web platform that helps Vietnamese candidates turn a specific job description (JD) into a preparation plan mapped to interview questions, then self-practice or book a mock interview with a mentor and receive structured feedback.

## Documentation status

- Current requirement sources: [Project Vision and Scope](Project_Vision_and_Scope/Project_Vision_and_Scope.md), [Product Backlog and Acceptance Criteria](Project_Vision_and_Scope/Product_Backlog_and_Acceptance_Criteria.md), and `refs/` for methodological criteria.
- Documentation set creation date: 12/08/2026.
- "Interview Practice Platform" is a working name.
- An internal planning baseline has been recorded; official approval still requires Sponsor signature in the Project Charter.
- MVP scope excludes an AI interviewer, integrated video calls, and automatic payment.
