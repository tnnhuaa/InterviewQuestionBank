## Slide 009 — Responsibility Assignment Matrix

_PDF page 2, handout panel 3_

```text
Responsibility Assignment Matrix
•
Responsibility Assignment Matrix (RAM), also known as
•
RACI matrix (Responsible, Accountable, Consulted, and Informed
matrix), or
•
LRC (linear responsibility chart)
•
describes the participation by various roles in completing tasks or
deliverables for a project.
•
Responsibility can be shared.
•
Accountability cannot be
shared. It is something you
hold a person to only after a
task is done or not done.
```
