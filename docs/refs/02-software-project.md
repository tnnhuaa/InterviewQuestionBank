## Slide 009 — Product Scope vs. Project Scope

_PDF page 2, handout panel 3_

```text
Product Scope vs. Project Scope
• In the project context, the term scope can refer to:
– Product scope. The features and functions that
characterize a product, service, or result; and/or
– Project scope. The work performed to deliver a product,
service, or result with the specified features and functions.
– The term project scope is sometimes viewed as including
product scope.
```

## Slide 013 — Operations and Projects [2]

_PDF page 3, handout panel 1_

```text
Operations and Projects [2]
• Projects are temporary in nature and have definitive start
dates and definitive end dates, use original processes,
produce unique results.
• Operations are ongoing and repetitive, use the same
processes, produce the same results.
• Project may come from the need of operations improvement.
```

## Slide 020 — Projects Success and Failure

_PDF page 4, handout panel 2_

```text
Projects Success and Failure
•
Success: The project is completed on time and on budget, with all
features and functions originally specified and the customer is happy.
•
Challenged: The project is completed and operational, but over
budget, late, and with fewer features and functions than initially
specified.
•
Failure: The project is canceled before completion, or delivered and
never used.
```
