## Evidence policy

- Git history proves changes, not formal acceptance.
- A code or configuration file proves implementation presence, not successful operation.
- A health response proves process availability at capture time, not readiness or complete E2E behavior.
- Local test execution and GitHub Actions CI are reported separately because the current CI workflow does not run `npm test`.
- Forecasts are not commitments, and proposed quality targets are not reported as achieved without measurements.
- Original-language screenshots are identified as source evidence; report prose and captions remain English.
- Credentials, private JD content, meeting links and personal data are excluded.

## Before printing

- Confirm the committed documentation revision from Git history before printing.
- Record the human reviewer and review date if required by the examiner.
- Print figures in color and keep captions with their figures.
- Re-run link checks after any file rename.
